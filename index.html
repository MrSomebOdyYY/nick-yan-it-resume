Personal project · Android

Track Speed for Android

I built Track Speed with Codex to compare standing starts on a closed course. I tested it on my Huawei Mate 60 Pro+. It records GPS speed and G-force offline and keeps the fastest valid run in each session.

Download Android APK ↓ View source on GitHub ↗
  • Java
  • Android SDK

View project details +

How the timing works

The app estimates when the vehicle crosses a speed threshold between two GPS readings. A gap longer than 2.5 seconds breaks the attempt, so missing readings cannot produce a new best time.

After a session

I can compare speed curves from earlier sessions or export timestamped GPS and motion-sensor samples to CSV. Recordings stay on the phone until I export them.

Task

Turn a selected vehicle, trip distance and driving conditions into a fuel estimate and budget comparison.

Implementation

Four Java classes, object arrays and console input. Passenger count, weather, road conditions, air conditioning and luggage adjust fuel use; traffic lights and stop signs are simulated. PrintWriter exports a text report.
